# 🔢 JavaScript Number Analyzer

A simple and interactive **Number Analyzer** built using HTML, CSS, and JavaScript. This project allows users to enter multiple numbers and perform different number operations instantly.

## 🚀 Live Features

- **Find Biggest Number** – Finds the largest number from the given input.
- **Find Smallest Number** – Finds the smallest number.
- **Count Odd Numbers** – Counts how many odd numbers are present.
- **Count Even Numbers** – Counts how many even numbers are present.
- **Calculate Total** – Calculates the sum of all entered numbers.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🎨 UI Design

- Retro calculator-inspired interface.
- LCD-style input and result displays.
- Metallic calculator body design.
- Responsive layout for smaller screens.
- Interactive buttons with click animations.

## 📸 How to Use

1. Open the Number Analyzer.
2. Enter numbers separated by commas.

   Example:
   `23,45,34,512,43,53`

3. Click any button to perform the desired operation.
4. View the result instantly on the screen.

## 💻 Getting Started

Clone this repository:

```bash
git clone YOUR_REPOSITORY_LINK
```

Open the project folder:

```bash
cd number-analyzer
```

Open `index.html` in your browser.
